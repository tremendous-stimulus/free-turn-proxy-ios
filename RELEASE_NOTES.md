## 1.6.0

### Новое
- **Режим «Туннель + WireGuard/AmneziaWG» (WG-in-WG).** Приложение само поднимает и терминирует WireGuard-туннель на устройстве вместо генерации `.conf` для стороннего клиента — не нужно вручную переключаться между AmneziaWG и Free Turn. Маршрутизация пакетов по адресу назначения идёт через встроенный netstack, минуя внешний VPN там, где это указано.
- **Раздельное туннелирование для режима «Туннель + WireGuard».** В настройках профиля — тумблер, режимы «Исключения» (перечисленное идёт мимо VPN) и «Включения» (через VPN идёт только перечисленное), источники списков: пресеты (белые списки РФ, два независимых списка заблокированного в РФ), ссылка, файл, ручной ввод.
- **Уровень логов на экране логов.** Настройка минимального уровня отображаемых записей (по умолчанию — предупреждения и хуже), текст логов теперь выделяется и копируется.
- **Диагностические ID для поддержки.** Пять тапов по номеру версии во вкладке «Помощь» показывают ID приложения и сессии — те же, что уходят с логами в телеметрию.

### Внутреннее
- Маршрутизатор WG-in-WG (`golib/ftun`) переведён с линейного перебора подсетей на бинарный поиск по диапазонам плюс LRU-кэш решений на горячем пути — список из десятков тысяч подсетей больше не сказывается на скорости туннеля.

## 1.5.0

### Новое
- **Миграция ядра на v2.1.1.** Новый JSON-конфиг вместо флагов командной строки, статус подключения и логи приходят пушем от ядра вместо разбора текстовых строк.
- **Профили обфускации `rtpopus2`/`rtpopus3`** в дополнение к `rtpopus` — можно подключаться к серверам на новых профилях.
- **`freeturn://`-ссылки.** Приём (из QR, фото, «Открыть в…», диплинка) и генерация своих ссылок для обмена конфигурацией.
- **Расширенные настройки подключения**: DNS-режим, количество потоков, streams-per-cred, альтернативный TURN-узел, режим udp/tcp с bond.
- **Несколько VK-ссылок** для одной конфигурации вместо одной ручной ссылки.
- **Лимит авто-переподключения** — 5 попыток, после чего туннель гасится и приходит пуш «Подключение разорвано» вместо бесконечного бекоффа.
- **Напоминание об обновлении в SideStore.** Точную дату истечения подписи узнать нельзя (Refresh в SideStore не обновляет файл в бандле приложения) — вместо лживого обратного отсчёта теперь баннер раз в 3 суток с закрытием крестиком и пуш, если приложение не открывали 2 суток.

### Исправления
- Пуш «Нужно решить captcha» больше не дублируется при каждом протухании капчи в рамках одного эпизода переподключения — только на первой попытке.
- Остановка туннеля при висящей капче больше не оставляет мёртвое уведомление.

## 1.4.0

### Новое
- **Автопереподключение при обрыве туннеля.** Если туннель упал (после успешного коннекта), приложение само пробует переподключиться с растущим б
екоффом 1→2→4→8→15с. Статус «Переподключаемся через X с» — видно сколько ждать до следующей попытки.
- **Единый поток реконнектов.** Все источники потери связи (ошибка из библиотеки, сбой healthcheck-зонда, смена сети LTE↔Wi-Fi) идут через один и
 тот же цикл с бекоффом и пушами.
- **Пуши о статусе.** При сворачивании приложения во время потери связи приходит «Переподключаемся», а после восстановления — «Переподключились».

### Исправления
- При длительной потере телеметрии буфер логов больше не разъедал память — лимит 10к записей, новые строки после ужима не теряются.
- Поля VK-ссылки и «Создать звонок» теперь дизейблятся пока туннель подключён, чтобы случайно не сбить сессию.

## 1.3.0

### Новое
- **Телеметрия.** Приложение анонимно отправляет технические логи подключения — помогает находить сбои. Отключить можно в настройках вкладки «Логи».

- **Баннер истечения сертификата.** Предупреждает за 3 дня до истечения сертификата SideStore с инструкцией по обновлению.

- **Обновление библиотеки** до upstream samosvalishe/free-turn-proxy v1.5.2 (фикс VK авторизации, поддержка Android).
- **Версия и ссылка на GitHub** в низу вкладки «Помощь».

### Исправления

## 1.2.0

### Новое
- **Ручное решение VK captcha.** Если авто-решатель не справился, captcha открывается прямо в приложении (поверх экрана) — пройдите проверку, и подключение продолжится само.
- **Статус «Нужно решить captcha»** вместо ложной ошибки, пока вы решаете проверку.
- **Пуш-уведомление**, если captcha потребовалась в фоне (при автоподключении/шорткате) — по тапу откроется проверка.
- **Кнопка «Показать капчу»** рядом с «Отключиться», если окно случайно закрыли не решив.
- **Тумблер «Решать captcha вручную»** в расширенных настройках конфигурации — всегда показывать проверку, минуя авто-решатель.
